## Implemented boundaries

- Host adoption discovers and preserves existing product and agent instruction files. The bridge is preview-first and idempotent.
- Governance composes policies most-restrictively, performs preflight checks, requires explicit provider execution plans, and records append-only attempts without acquiring product authority.
- Provider execution separates configuration, destination, authorization, schema resolution, transport, response parsing, and audit. Recorded replay and OpenAI are adapters behind the same governed boundary.
- Research records preserve source, observation, claim, expression, disposition, rights, and batch identities. Browser-derived expressions cannot enter training or generation as reusable wording.
- Voice/tone compilation uses nine independent dimensions and interval intersection. Missing or conflicting evidence does not become an averaged universal voice score.
- The comparison corpus is project-owned synthetic data. Leakage groups and rights records are complete, and a verifier scans the recorded evidence corpus for distinctive-expression similarity.
- Voice prompt context retains the complete map, graph, lineage, approval, and task-scope qualification input locally and replays it before every prompt. Only bounded feature intervals, immutable references, and a proof digest reach model context; raw evidence and the proof graph remain local. A self-digested or tampered voice profile is not sufficient.
- Writer APIs validate model output and reject raw observed-expression fields from prompt compilation.
- Raw `public` prompt context is disabled at both compilation and direct provider execution. Public-source material must first become a reviewed, rights-bounded transferable projection; a generic label cannot authorize egress.
- Approved-pattern prompt context now replays the complete pattern, rights disposition, conforming lineage, task scope, and current product approval. The locally verified evidence proof is digest-bound to the prompt context but stripped before model egress; raw observed expression remains excluded.
- Project-fact prompt context now replays the complete product-owned fact, exact source set, provenance, task requirement, project scope, current semantic approval, and evaluation time before compilation and again before provider execution. Only the bounded claim, observation strength, limitations, immutable refs, and proof digests reach model context; raw source locators and the local proof graph do not.
- Review-finding prompt context now replays the complete task packet and deterministic review input/report, requires exact project, task, occurrence, evidence, and selected-finding membership, and rejects automatic-rewrite findings. Only the bounded diagnostic, uncertainty, next action, immutable refs, and proof digests reach model context; source expressions and the local replay graph remain local. Compilation and provider execution require exact, duplicate-sensitive equality between the authorized finding set and prompt egress, so a self-authored extra finding cannot ride beside a valid proof.
- Product-example prompt context now replays the complete product-owned expression version, expression slot, semantic message, current semantic approval, exact task packet, and complete provenance lineage. An approved example requires null finding evidence; a counterexample requires one exact deterministic review-finding replay whose occurrence matches expression, locale, and channel and whose finding is explicitly approval-scoped. Only the product-owned expression, bounded semantic metadata, deterministic counterexample rationale/action, immutable refs, and proof digests reach model context. Raw source locators, review inputs, and lineage records remain local, and direct provider execution requires duplicate-sensitive equality with prompt egress.
- Recursive learning is deterministic and development-only: sealed datasets, exact Task 4 vectors, pairwise logistic fitting, prediction/ranking, evaluation, shadowing, drift checks, and rollback simulation do not auto-promote or publish content.
- Human calibration is executable but evidence-conservative: privacy-minimal qualification records bind consent, locale/channel/dimension scope, training evidence, and conflicts before expressions are revealed; assignments omit canonical candidate identities and expected answers; calibration/test leakage groups and raters are disjoint; model evaluation requires separate model-processing consent; complete qualification, assignment, rating, and mapping evidence is replayed; and held-out metrics remain null until every expected test pair has three independent agreeing human judgments.
