# Runtime promotion map

This map connects the explanatory knowledge packs to integrated runtime rule packs.

| Knowledge pack | Runtime pack | Current deterministic coverage |
|---|---|---|
| `context-state` | `uxw-pack.context-state` | Evidence presence and actor authority |
| `agency-consent` | `uxw-pack.agency-consent` | Required material choice |
| `errors-recovery` | `uxw-pack.errors-recovery` | Unknown-outcome retry and recovery availability |
| `controls-forms` | `uxw-pack.controls-forms` | Control-state evidence |
| `structure-navigation` | `uxw-pack.structure-navigation` | Advisory destination consistency |
| `conversation-ai` | `uxw-pack.conversation-ai` | Generated/hybrid identity and limits |
| `voice-expression` | `uxw-pack.voice-expression` | Semantic-invariant mapping and preservation |
| `accessibility-localization` | `uxw-pack.accessibility-localization` | Required locale specialist review |
| `research-governance` | `uxw-pack.research-governance` | Candidate authority boundary |

Coverage is deliberately narrower than the knowledge base. A concept becomes executable only when its required facts can be established deterministically or its uncertainty can be represented honestly.
