# Practitioner field-kit tabletop rehearsal

## Result and evidence boundary

**[Research finding]** A static tabletop can trace the field kit's normal, consent-change, unsafe-artifact, multilingual, withdrawal, deletion, and handoff-quarantine branches without requiring personal or proprietary data. All seven branches have an explicit stop, state change, or record destination in the current kit.

**[Research finding]** This tabletop does not close the Phase 1 rehearsal gate. It did not involve a participant, moderator-observer pair, approved research environment, processor, interpreter, data store, or independent coders; it therefore cannot establish understandable consent, real timing, safe operator behavior, accessibility, language quality, deletion propagation, or inter-rater reliability.

The authoritative inputs were:

- [Practitioner decision-reconstruction field kit](practitioner-field-kit.md)
- [Practitioner decision-reconstruction protocol](practitioner-decision-reconstruction-protocol.md)
- [Materials and access register](materials-and-access-register.md#phase-1--practitioner-study-readiness)
- [Synthetic checkout-recovery fixture](shared-benchmark-fixture-specification.md#known-behavior-packet)

No statement in this note is a practitioner account, participant observation, semantic approval, study authorization, or product outcome.

## Method

One operator traced the frozen moderator guide and state transitions on paper using a wholly synthetic decision case. Each branch was checked for:

1. a defined entry condition;
2. the exact action or question allowed at that point;
3. an observable stop or state transition;
4. separate evidence, control, decision, delivery, and evaluation records where applicable;
5. a safe destination or explicit absence for every resulting record; and
6. a reason the path cannot yet be treated as operationally verified.

The operator did not simulate a person by inventing attitudes, expertise, consent, quotations, or organization facts. Scripted values below are test inputs, not reported experience.

## Findings and changes required before a live synthetic rehearsal

**[Research finding]** The field kit contains a path for every branch required by its pre-pilot checklist. The main remaining problem is materialization, not a missing interview question: approved configuration values, a safe meeting/capture environment, access-separated stores, incident and deletion owners, trained roles, and testable handoff tooling do not exist.

**[Research finding]** A document-only path can verify logical coverage but cannot verify that an operator can complete the path safely. The next rehearsal must use two trained humans, synthetic materials only, actual approved tools, recording/capture off by default, a disposable quarantine object, and a synthetic derivative chain whose deletion can be verified.

**[Open question]** The current kit is Markdown rather than a fillable stateful instrument. Before S001, determine whether the approved operational system can enforce required fields, conditional consent paths, state transitions, access separation, and immutable consent history without copying restricted data into convenience tools.

**[Open question]** The 60–75 minute pilot criterion remains untested. A timed human rehearsal must record segment duration and confirm that interpretation time does not compress consent, artifact safety, playback, or closing.
