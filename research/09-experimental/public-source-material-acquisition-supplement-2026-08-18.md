# Public-source material acquisition supplement for the seven-product study set

## Result and evidence boundary

**[Cross-source finding]** A second read-only primary-source pass on 18 August 2026 found materially stronger immutable pins and operational documentation for the seven named study systems. It does not make any packet product-ready or execution-ready. All seven remain `public-source-incomplete` under [`PSF-r1`](public-source-product-study-and-judge-baseline-2026-08-17.md#source-only-rubric-psf-r1).

The strongest new source discoveries are:

- commit- and tag-pinned source for VOICE.md, the UX Writing Skill, content-md, and Ditto CLI `5.7.2`, plus a pinned Ditto agent-setup `0.6.0` snapshot;
- publisher-reported SHA-256 digests for the UX Writing Skill release ZIP, ContentRX Python artifacts, and content-md release binaries;
- more exact MCP/API/authentication, transmitted-data, processor, region, retention, output, export, plan, revocation, telemetry, and cleanup contracts for Ditto, ContentRX, the UX Writing Skill installer, Frontitude, GitCMS, VOICE.md, and content-md; and
- explicit contradictions that a later source judge must retain rather than reconcile by assumption.

No account was opened; no login, OAuth flow, token, API key, connector, install, package download, repository clone, product interaction, external write, or desktop Computer Use operation occurred. No page or artifact body was retained locally as an evidentiary capture. Publisher asset digests and Git object IDs below are source metadata, not hashes of a locally captured `ProductStudyEvidenceRecord`.

A later source-only receipt pass created seven schema-valid [`ProductStudySourceRecord` hash receipts](public-source-hash-receipts-2026-08-18.jsonl), one official locator per product. Each receipt hashes the decoded HTTP response-body bytes observed at its exact UTC timestamp, records the effective URL and response metadata, and explicitly says the body was discarded because no approved snapshot store exists. These receipts improve locator/version integrity; they are not retained source snapshots, `ProductStudyEvidenceRecord` captures, desktop observations, or independently replayable evidence.

A separate [14-route preflight receipt set](public-b0-route-preflight-hash-receipts-2026-08-18.jsonl) now mirrors every URL in the exact B0 script. Thirteen routes returned HTTP `200` to the certificate-verified research client; `https://contentmd.org/` returned HTTP `403`. The web index could render that route through a different access path, so the record preserves the disagreement instead of calling the page absent or substituting indexed output for desktop evidence. These fourteen records are also source-only transient-response receipts and earn no B0 credit.

This source-only update earns **no B0 credit**. `P3-03` remains `specified-not-materialized`: no route-pass capture, schema-valid evidence record, retained source snapshot, two-pass reconciliation, or product-level B0 claim set was created. The official locators below were accessed read-only on `2026-08-18` local time; access establishes only the bounded source observations recorded here, not product or runtime behavior.

This supplement proves only what the linked official material exposed in the declared public-access scope. It does not prove installed bytes, runtime behavior, offline operation, telemetry absence, cleanup completion, security/privacy implementation, fixture compatibility, content quality, or product performance.
