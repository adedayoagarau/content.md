# Participant-materials assembly manifest template

## Authority and participant boundary

**[Proposal]** Use this manifest to enumerate the material classes required by P1-03 and conditional P1-08. It is not a participant packet and contains no participant-facing copy, recipient, delivery, consent choice, contact detail, participant record, translation, approval, or language assignment.

Current disposition: `not-for-use`. Every artifact, version, review, accessibility, language, delivery, and owner reference is `not-established`. Do not distribute, preview as approved material, or use this file to recruit, screen, schedule, collect consent, or start a session.
