# Beacon Checkout Lab

**Status:** Active

## Product name

Beacon Checkout Lab

## One sentence

Beacon Checkout Lab is a wholly synthetic web application where merchant teams create workspaces, configure a test checkout, and inspect simulated payment states.

## Primary audience

merchant content designer

## Primary job

Create workspaces and inspect simulated payment states.

## Product scope

A shopper is the affected user in checkout previews. After a payment submission, the result can be unknown; the product must direct the user to check status before attempting another payment. Deleting a workspace removes local drafts and entered test data but does not cancel or reverse a provider attempt.

No product superlative, guaranteed outcome, or external publication authority is established by this fixture.
